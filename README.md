# CleanMark AI API

High-performance Web-to-Markdown and Data Extraction Microservice for LLMs, RAG, and Web Developers.

## Features
- **Fast Web-to-Markdown Extraction** (`POST /v1/extract`): Strips boilerplate, ads, scripts, and navigation to return clean markdown with word count and token metrics.
- **Deep Email & Spam Verification** (`POST /v1/validate-email`): Validates format, disposable provider blacklists, and real-time DNS MX records.
- **Health Check** (`GET /v1/health`).

## Running Locally
```bash
npm start
```
